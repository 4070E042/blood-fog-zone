簡短說明

- 這是一個小型測試頁面，包含玩家移動與左上角 HUD（血量與生存時間）。

如何測試

1. 在瀏覽器中開啟 `index.html`（直接雙擊或用本機伺服器）。
2. 首次載入會先看到開始選單，按下「開始遊戲」後才會隱藏選單並開始計時與生成敵人。
3. 使用 `WASD` 或方向鍵控制玩家移動，玩家會被限制在畫面內。
4. 左上角會顯示 `血量: 100`、目前分數與持續增加的 `生存時間`（秒）。

音效

將音效檔放到 `sounds/` 資料夾：

- `sounds/hit.mp3` — 玩家揮棍命中敵人時播放
- `sounds/hurt.mp3` — 玩家被殭屍碰到受傷時播放
- `sounds/zombie1.mp3` — 敵人生成或靠近玩家時隨機播放
- `sounds/zombie2.mp3` — 敵人生成或靠近玩家時隨機播放
- `sounds/death.mp3` — 玩家死亡（HP 0）時播放

若資料夾中沒有檔案，程式會安全忽略播放錯誤，不會中斷遊戲。

注意

- 本專案現包含敵人生成、敵人追擊、玩家揮棍攻擊、打擊/殭屍音效與 Game Over。
